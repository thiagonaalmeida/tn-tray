# Support

Use [Issues](https://github.com/thiagonaalmeida/tn-tray/issues) for bug reports and [Discussions](https://github.com/thiagonaalmeida/tn-tray/discussions) for questions, feedback, and feature ideas.

When reporting a bug, please include:

- Thunderbird version.
- Windows version.
- Whether the issue happens with "Use only this extension's tray icon" enabled or disabled.
- Whether diagnostic logging (Settings > TN Tray > Enable diagnostic logging) shows anything relevant — you can attach the log file (use the "Show log file" button in the settings page to find it).
- A screenshot or short screen recording when possible.
